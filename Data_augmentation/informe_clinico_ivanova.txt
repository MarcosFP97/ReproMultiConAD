# Reglas técnicas de generación para replicar hallazgos clínicos en la lectura del Quijote
# Formato: lista de Python

# Reglas generales
1. Longitud de frase: entre 5 y 20 palabras por frase.
2. Tipo de errores léxicos: sustituciones semánticas, parafasias, omisiones, circunlocuciones.
3. Uso de marcas CHAT: [/], [//], &-eh.

# Reglas específicas por grupo diagnóstico
## Control Sano (HC)
- Longitud de frase: 10-15 palabras.
- Errores léxicos: raros, omisiones simples.
- Uso de marcas CHAT: [/] para correcciones, [//] para pausas.

## Deterior Leve (MCI)
- Longitud de frase: 8-12 palabras.
- Errores léxicos: parafasias, vacilaciones, pérdida de ritmo.
- Uso de marcas CHAT: [/] para parafasias, &-eh para vacilaciones.

## Demencia
- Longitud de frase: 3-7 palabras.
- Errores léxicos: anomia, sustituciones semánticas, pérdida de estructura gramatical.
- Uso de marcas CHAT: [/] para anomia, [//] para pausas prolongadas.

# Reglas específicas por MMSE
## MMSE 25-30
- Longitud de frase: 10-15 palabras.
- Errores léxicos: raros, omisiones simples.
- Uso de marcas CHAT: [/] para correcciones, [//] para pausas.

## MMSE 20-24
- Longitud de frase: 8-12 palabras.
- Errores léxicos: parafasias, vacilaciones, pérdida de ritmo.
- Uso de marcas CHAT: [/] para parafasias, &-eh para vacilaciones.

## MMSE <20

- Errores léxicos: anomia, sustituciones semánticas, pérdida de estructura gramatical.
- Uso de marcas CHAT: [/] para anomia, [//] para pausas prolongadas.

# Reglas para partes específicas del texto
## Palabras arcaicas ("astillero", "adarga")
- Mayor probabilidad de errores léxicos en estas palabras.
- Uso de marcas CHAT: [/] para correcciones, [//] para pausas prolongadas.

## Enumeraciones complejas
- Mayor probabilidad de pérdida de ritmo o vacilaciones.
- Uso de marcas CHAT: &-eh para vacilaciones.
